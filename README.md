# Sahil Ambekar

### AI Automation Developer

I build automations that put LLMs to work on real business processes: n8n workflows, document extraction,
retrieval and agents, running on local models (Ollama) or cloud models, and connected to the systems a business
already has (ASP.NET, SQL Server, spreadsheets, email).

**What I automate**

- **Intake and routing:** emails, forms and tickets classified, extracted and sent to the right table or person
- **Documents:** invoices and purchase orders turned into validated JSON, Excel and SQL rows
- **Answers from your own data:** retrieval with citations over documents, and read-only SQL agents with guardrails
- **AI inside existing apps:** summaries, reply drafts and knowledge-base answers embedded in .NET business apps

I care about the unglamorous parts: schema validation, retries and fallbacks, human approval where it matters,
and evals that say how well something works, including where it fails.
